# dsa-typescript-solutions 🚀
"A collection of fundamental algorithmic problems solved with strict TypeScript, focusing on clean code and efficiency."

## 🛠 Tech Stack
*   **Language:** TypeScript
*   **Environment:** Node.js
*   **Tooling:** ts-node / tsc

## 📂 Problems Solved

### 1. Flood Fill
- **Concept:** Depth-First Search (DFS).
- **Description:** Implements the "paint bucket" tool logic to change colors of connected pixels.

### 2. Trapping Rainwater
- **Concept:** Dynamic Programming / Two Pointers.
- **Description:** Calculates how much water can be trapped between bars after raining.

### 3. Climbing Stairs
- **Concept:** Fibonacci Sequence / Dynamic Programming.
- **Description:** Calculates the number of distinct ways to reach the top of a staircase.

### 4. Jump Game
- **Concept:** Greedy Algorithm.
- **Description:** Determines if you can reach the last index of an array based on maximum jump lengths.

### 5. Rod Cutting
- **Concept:** Dynamic Programming.
- **Description:** Finds the maximum profit obtainable by cutting a rod into pieces and selling them.

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the project:**
   ```bash
   npm run dev
   ```
